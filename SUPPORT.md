# Support

Use a public GitHub issue for installation, usage, and non-security bug
questions. Before opening a report, review the README, guides, and known
limitations. Discussions are intentionally disabled for this repository so
support stays searchable and triageable in one place.

Do not post security vulnerabilities, real policy files, screenshots, audit
logs, confirmation tokens, local executable paths, or other machine-specific
data publicly. Follow [SECURITY.md](SECURITY.md) for vulnerability reports.
